How Delta Moves a Call Value

Interactive Example — See Delta in Action

Delta tells you how much an option price should move when the stock moves $1. This interactive example uses a $100 stock, $4.00 call, and Delta 0.50. Drag the slider to see the math: Call Change = Stock Change × Delta.

Mindset: Delta is not fixed — it changes as the stock moves, time passes, and IV changes. This 60 DTE, ATM example (Delta ≈ 0.50) is for learning the math, not a trading signal.

Why Delta Matters

  • ATM Delta ≈ 0.50: Call moves about half the stock move. Stock +$2 → Call +$1 (before other factors).
  • ITM Delta → 1.0: Deep ITM calls behave more like stock.
  • OTM Delta → 0: Far OTM needs a bigger stock move to gain value.
  • Delta is not P/L: Remember ×100 multiplier and time decay.
